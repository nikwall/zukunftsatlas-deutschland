# Zukunftsatlas Deutschland 2035

Wächst Deutschland in seine Rechnung hinein? Neun Unsicherheiten, zwei Achsen, vier Felder und 39 Signale, ausgehend vom Jahresgutachten 2026/27 des Sachverständigenrates.

Seite: https://nikwall.github.io/zukunftsatlas-deutschland/

- `index.html`, `assets/`: die veröffentlichte Seite (GitHub Pages).
- `quelle/`: Inhalt (`atlas.toml`), Vorlage und Build der Seite.
- `basisraten/`: Skripte, mit denen die Basisraten aus öffentlichen Daten nachgerechnet werden.
